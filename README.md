### 💻 Tecnologias Utilizadas
- **HTML5** — Estruturação das páginas do sistema
- **CSS3** — Estilização personalizada com foco em design moderno e responsivo
- **JavaScript** — Lógica de funcionamento, interatividade e gerenciamento de dados

### 🚀 Funcionalidades
* Adicionar e gerenciar equipamentos
* Listagem e pesquisa de itens
* Sistema de controle de usuários e navegação

### 🌐 Como Acessar
Clica no botão **"Acessar BrutoFit Ao Vivo"** no topo da página para testar a aplicação diretamente no teu navegador!
